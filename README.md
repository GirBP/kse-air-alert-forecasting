# KSE: прогноз типової тривалості переривання після тривоги

Робочий Python-проєкт для нерегулярного часового ряду повітряних тривог Києва. Практична задача — після оголошення оцінити типову тривалість переривання діяльності. Статистична ціль: **ретроспективна тривалість зареєстрованої закритої події при її початку**, хвилини. Початок тривоги, добове навантаження й кількість ракет не прогнозуються.

Метод — **медіана останніх 30 фактично завершених тривог**. Поточний відбій у прогноз не входить. Джерела не зливаються; нових моделей/ознак/налаштувань на цьому етапі немає.

## Запуск із чистої копії

Потрібні Python 3.10+ і IANA Europe/Kyiv; перевірено CPython 3.14.7 у чистому venv. Лише стандартна бібліотека, без pip-залежностей і API-токенів. Мережа потрібна один раз для pinned CSV.

```sh
python3 -m venv .venv
.venv/bin/python scripts/fetch_latest_input.py --project-root .
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m unittest discover -s tests_latest -v
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m kse_latest evaluate --project-root .
.venv/bin/python scripts/verify_latest.py --project-root .
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m kse_latest demo --project-root . --show-actual
```

Демо — **відтворення історичного прикладу** з вересня: початок 20.09.2026 00:12:00.586, прогноз 24.069 хв, 66 завершених подій в історії, використано 30; факт 12.424 хв показується окремо. Час історичної публікації/виправлення невідомий; доведена причинність за часом події, не оперативна доступність архівної версії.

## Публікація та подання

Код і авторська документація — MIT. Ліцензію перепоширення вхідного mirror CSV не встановлено, тому raw, детальні event-level таблиці й приватні чати **не публікуються**; pinned downloader відтворює потрібний локальний вхід з URL/SHA. Повні AI-експорти подаються окремо для форми. Журнал рішень не замінює їх. Справжні Codex-тексти підготовлено локально; зовнішні ChatGPT/Gemini/Antigravity-експорти ще потрібно додати власнику.

Попередні v1/v2 і Vadimkin-фінал збережено локально незмінними як історичні результати. Їхній вересневий край не підміняє новий жовтневий експеримент. Початкова добова задача й широкий збір залишаються окремими незавершеними напрямами. Вимоги KSE тут — перелік, наданий користувачем; дедлайн **12.10.2026 23:59 Europe/Kyiv**.
