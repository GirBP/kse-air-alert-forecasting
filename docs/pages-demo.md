# GitHub Pages: калькулятор і дослідження

Сайт: https://girbp.github.io/kse-air-alert-forecasting/. Версія інтерфейсу: **pages-v1.2**. Це статичний сайт з українською та англійською мовами, історичним калькулятором і порівняннями збережених результатів. Сам факт посилання не підтверджує розгортання: точні файли зв’язано SHA-256 у `web/release.json`.

## Два види оцінки

Незалежні чекбокси дозволяють обрати оцінку від початку, залишок або обидві.

- **Від початку:** незмінна медіана останніх 30 завершених київських записів. JavaScript переносить контракт Python `kse_latest.forecast`, включно з перевіркою версій, тотожності міста, повторів, перекриттів і часових меж. Поточний і майбутній відбої не використовуються. Python-ядро, зафіксований протокол і попередні метрики не змінені.
- **Залишок:** нова, явно дослідницька адаптація емпіричного K0. Користувач вводить цілі невід’ємні минулі хвилини `e` й тим самим задає умовний сценарій «подія досі триває». Історія містить усі придатні записи, завершені до введеного початку. Залишки `duration - e` обчислюються тільки для `duration > e`; відповідь — їхня медіана, якщо записів щонайменше 5. Це не віднімання від початкової медіани 30. У v4 K0 історія оновлюється на кожному моменті оцінювання; на сайті вона консервативно зафіксована при початку. **Точність цієї адаптації окремо не виміряно; жодна метрика v4, зокрема AFT 20,6 хв, їй не приписується.**

Момент оцінки залишку — початок плюс введені хвилини; майбутній момент відхиляється. Якщо початок (T0) або момент оцінки (T1) досягає межі архіву, відповідна оцінка недоступна. Для T0 окремо може бути показано історичний орієнтир на межі, а для T1 число не підставляється. Початок, активність тривоги та поточний офіційний статус не перевіряються. Кінець запису не доведено тотожним офіційному відбою.

Дата й час — Europe/Kyiv незалежно від часової зони браузера. «Використати сьогоднішню дату» бере київську дату, оновлює її при надсиланні форми й дозволяє повернутися до ручного введення. Неоднозначний/неіснуючий місцевий час при переходах літнього часу відхиляється. Мова зберігається локально; її зміна не змінює введення чи розраховані числа. Видимі дробові метрики й тривалості мають один знак після коми; повна точність збережена у JSON/CSV.

## Походження даних

Браузер анонімно отримує CSV безпосередньо з джерела:

`https://raw.githubusercontent.com/JustJimer/ukraine-air-alert-stats/c5b3bd012c7694e63115999a7bbd0b683eaa8d24/archive/alerts_in_ua.csv`

SHA-256: `fe79c5726a1a9db9f560d6dad1de1b46f16d93b9b44ff54a2078228cf56cbc0d`. Межа версії: **12.10.2026 10:51:36 UTC / 13:51:36 Europe/Kyiv**, 247 рядків Києва. Завантаження старого файла не робить його актуальним. Введені дані залишаються у браузері; не передаються в URL або тіло запиту. Помилка мережі, CORS, цілісності чи структури не замінюється синтетичними даними. Чужі event-level CSV, ключі й приватні AI-логи не хостяться.

Час первинної публікації, отримання й виправлення історичних версій та повнота спостереження невідомі. Перевірена послідовність подій не доводить реальної доступності цих версій у минулому.

## Таблиці експериментів

`reports/website-experiments/` містить копії авторських агрегованих результатів, вибрані параметри та маніфест походження з SHA. `scripts/build_pages_experiments.py` перевіряє ці хеші й відтворює `web/assets/experiments.json` без навчання або нового вибору моделей.

На сайті **150 рядків у 14 групах**: 87 придатних сімейств v3, 2 зафіксовані контрольні рядки, 61 порівняння v4 (нейронні запуски об’єднано середнім метрик). Це не 150 унікальних моделей: контрольні методи й варіанти повторюються між задачами й вибірками.

- H: Vadimkin official. N: окреме дзеркало alerts.in.ua. Цілі джерел не зливаються.
- T0: тривалість при початку. T1: залишок під час перебігу, з усередненням втрат спочатку всередині події, потім між подіями.
- Сортування MAE за повною точністю, від меншої до більшої, тільки всередині однієї групи. Різні періоди, S0/S1, початок/залишок і неповна вибірка K0 (815 замість 816 оцінок) розділені.
- Нейронні метрики усереднені за трьома seeds; найкращий seed не обирається. Навчальні кількості v4 скопійовані з fit-costs; часовий cutoff наведений у деталях.
- Параметри v3 вибрані на development до replay. Ці періоди вже переглядалися, отже рейтинги не є новим незалежним тестом або підставою автоматично замінити основну модель.
- Добову SARIMA не оцінено без підтвердженого календаря спостереження. N pooling після фільтрів має лише Київ; його цифри не доводять міжміського перенесення.

Таблиці показують основні збережені replay-порівняння, а не кожний службовий fit, development-fold чи аналіз затримок. Великі checkpoints, raw, географічні входи та повне середовище v3/v4 залишаються локальними. Public clone відтворює основний Python-метод і таблиці сайту, **не всю широку навчальну серію**.

Primary84 і latest91 збережені окремо: 84 записи 1–11 жовтня й 91 запис 1–12 жовтня з неповними останніми днями. Вибірки перетинаються. Нової незалежності чи підтвердженої практичної користі не заявлено.

## Приклади й незалежний аудит

Необов’язковий блок «Як читати оцінку» містить три вигадані навчальні приклади, а не сценарії для введеного користувачем початку. `scripts/build_pages_demo.py` обчислює їхні прогнози справжнім Python-методом на авторських синтетичних тривалостях; факти приєднуються після прогнозу. Початкові приклади й агрегати не змінено.

[Попередня незалежна арифметична перевірка](../reports/latest91/research-audit-summary.json) відрізняється від перевірки нової версії інтерфейсу. Новий сайт не отримав автоматично приймання старого commit. Попередній аудит виявив незавершений prospective logger і ризики вільного historical helper; вони не стали виправленими через UI-оновлення. Ці компоненти не виконуються публічним калькулятором. Наступне дослідження потребує нових даних із журналом їх отримання та критерію практичної користі.

## Перевірка й запуск

```sh
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests_latest -v
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests_web -v
PYTHONPATH=src python3 scripts/build_pages_demo.py
python3 scripts/build_pages_experiments.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory web
```

Site contracts перевіряють Python/JS parity початкового методу, київську дату у трьох часових зонах, формулу залишку незалежними прикладами, мінімальний розмір хвоста, часові межі та незмінність при додаванні поточних/майбутніх подій. Таблиці звіряються зі збереженими агрегатами, повнотою груп і середніми seeds. Окремо браузером перевіряються мови, два чекбокси, сьогоднішня дата, застарілий архів і вузький екран. Це програмні перевірки, не оцінювання точності нової адаптації K0.

Workflow GitHub Pages запускає тести й публікує тільки `web/`. Приватні розмови готуються окремо згідно з обраним користувачем складом: виконавець, аудитор і Gemini; чат організатора виключено. Відсутній Gemini-експорт не підміняється переказом.
