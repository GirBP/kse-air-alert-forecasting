## Що публікується

Авторський код, тести, інструкції, protocol/lock/opening, метадані походження, агреговані метрики, короткий аналіз великих помилок і reflection. LICENSE покриває лише наш код і авторську документацію. Чужого коду дзеркала не копіюємо до репозиторію; inspected copies залишаються локальними.

Для дзеркала GitHub API повернув license=null, LICENSE URL — 404. У переглянутій документації alerts.in.ua не встановлено відкриту ліцензію перепоширення CSV. Публічність завантаження не прирівнюємо до дозволу на перепоширення. Тому весь CSV, детальні event-level результати та старі raw gitignored; репозиторій надає власний pinned downloader і контрольну суму для локального отримання. GitHub пояснює різницю ліцензії та доступності: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository.

Київський портал вказує Open Data Licence для ресурсу; це не ліцензує незалежне дзеркало alerts.in.ua. Код Vadimkin має MIT, умови його первинних даних окремо не засвідчено. Kaggle метадані попередньо вказують CC BY 4.0 для Kyiv та CC BY-NC-SA-4.0 для attacks; вони не потрібні у цій публічній версії. Жодних чужих великих архівів до GitHub не включено.

AI-експорти містять повні приватні розмови й надаються окремо для форми, не до публічного GitHub. Журнал рішень є поясненням методології, не заміною повного AI-логу.
